# 현장 폴더 (진행중 · 미체결 · 완료 · 지역별) — short design

## Why

현장이 늘면서 상태 버튼 8개(상담중 … 보류)로는 "지금 손이 가는 현장", "아직 계약 안 된 현장", "끝난 현장", "어느 동네 현장"을
한눈에 나누기 어렵다. 사장님 요청: 현장을 미체결, 지역별(시 단위), 완료, 진행중 폴더로 나눠 보기.

## What (approved sketch, 2026-11-24)

현장 관리 탭의 현장 목록 왼쪽에 폴더 목록을 두고, 고른 폴더의 현장만 보여 준다. 상태 버튼 8개는 폴더로 바꾼다.

```
┌ 폴더 ─────────┐
│ 전체      32  │
│ 진행중     8  │   계약 · 시공중
│ 미체결    12  │   상담중 · 상담완료 · 실측 예정 · 견적 · 보류 (상태가 비었거나 모르는 값도 여기)
│ 완료      12  │   완료
│ 지역별 ▾      │
│   의왕시   9  │   주소에서 '○○시/군'을 읽어 자동으로 나눈다
│   서울     7  │   서울특별시·서울시 → 서울 (광역·특별시는 짧은 이름)
│   지역 미정 2 │   주소가 없거나 시·군을 못 읽으면
└───────────────┘
```

- 각 줄의 상태 배지는 그대로 둔다.
- 폴더 숫자는 검색어와 상관없이 휴지통에 없는 현장 전체를 센다. 검색은 고른 폴더 안에서 걸린다.
- 현장별 보기와 고객별 보기 모두 폴더를 따른다. 폴더를 고르면 현장이 없는 고객은 고객별 보기에서 숨는다(전체에서는 보인다).
- 고른 폴더와 보기 방식은 브라우저에 기억한다. 기억한 지역 폴더에 현장이 더는 없으면 전체로 돌아간다.
- 지역 폴더는 현장 수가 많은 순, 같으면 가나다순, '지역 미정'은 맨 끝.
- 좁은 화면에서는 폴더가 목록 위에 버튼 줄로 나온다.

## Region rule

주소 앞쪽 네 낱말 안에서 처음 나오는 것:
- 서울·부산·대구·인천·대전·울산(+특별시/광역시/시), 광주(+광역시), 세종(+특별자치시/시) → 짧은 이름 (서울, 부산 …, 세종).
  '서울', '세종'처럼 꼬리 없이 쓴 이름은 주소의 첫 낱말일 때만 (우편번호는 세지 않음). '산본 세종 6단지'는 군포의 아파트, '경기 광주'는 경기 광주시.
- 한글로 끝이 '시' 또는 '군'인 낱말 → 그대로 (의왕시, 수원시, 양평군, 제주시). '광주시'는 경기 광주시로 본다.
  '○○특례시'는 '○○시'로 (수원특례시 → 수원시). '평촌신도시'처럼 '도시'로 끝나는 낱말은 동네라서 시로 보지 않는다.
- 없으면 '지역 미정'. ('의왕 내손동'처럼 '시'를 빼고 쓴 주소는 지역 미정 — 주소를 고치면 들어간다.)

## Approaches

1. **(chosen) 화면에서 상태·주소로 바로 나누기** — 저장 데이터는 그대로, 규칙은 순수 함수(`app/lib/site-folders.ts`)로 테스트.
   새 현장도 바로 맞는 폴더에 들어간다.
2. 현장마다 폴더 칸을 저장 — 직원이 직접 옮길 수 있지만, 상태와 따로 놀아 계약했는데 미체결에 남는 일이 생긴다. 요청과 맞지 않음.
3. 지역 칸을 따로 입력 — 정확하지만 기존 현장을 다 다시 입력해야 한다.

## Not now

- 폰 앱 현장 탭의 폴더 (요청하면 추가).
- 폴더와 지역을 겹쳐 고르기(예: 의왕시의 진행중) — 상태 배지로 구분 가능, 필요하면 나중에.
