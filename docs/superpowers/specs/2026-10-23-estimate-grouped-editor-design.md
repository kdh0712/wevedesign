# 공사별 견적 표: 템플릿·현장 견적 공통 편집, 평형 수량 조정, 견적을 템플릿으로 저장

작성일: 2026-10-23 · 상태: 검토 대기 · 앞선 설계: `2026-10-22-estimate-templates-design.md`

## 1. 목적과 범위

템플릿 작업 창(PR #29)에서 쓰기 시작한 "공사별 묶음 + 오른쪽 세부내역서" 배치를 현장 견적 화면까지 넓히고, 견적 입력을
빠르게 하는 기능을 더한다.

1. **공사 단위로 한 번에 다루기:** 공사 이름 바꾸기·합치기, 공사 복사, 공사 삭제.
2. **엑셀처럼 키보드로 입력:** Tab, Enter로 칸을 옮기고, 공사의 마지막 줄에서 Enter를 누르면 새 줄이 생긴다.
3. **현장 견적 화면에도 같은 배치 적용:** 공사별 표와 세부내역서를 넣고, 왼쪽 DB 패널은 접을 수 있게 한다.
4. **끌어서 순서 바꾸기:** 줄은 같은 공사 안에서만, 공사는 전체 순서를 바꾼다.
5. **평형에 맞춰 수량 자동 조정:** 기본은 꺼져 있는 옵션이다.
6. **"이 견적을 템플릿으로 저장" 버튼:** 새 템플릿으로 만들거나 기존 템플릿에 덮어쓴다.
7. 추가 요청: **공사별 색**, **세부내역서 크게 보기**.

성공 기준:

- 템플릿 작업 창과 현장 견적 화면이 같은 표 부품을 써서 공사 묶음·색·키보드·끌기·줄 메뉴가 똑같이 동작한다.
- 현장 견적의 줄 순서를 직접 정할 수 있다. 화면, 저장된 순서, 서류 출력의 세부내역서 순서가 같다.
- 실수로 끌어 놓아도 줄의 분류(카테고리)는 바뀌지 않는다.
- 평형 조정을 켜지 않으면 불러오기 결과가 지금과 같다.
- 기존 견적·템플릿 데이터는 변환 없이 그대로 열린다.

### 결정 사항 (대표님 답변, 2026-10-23)

| 질문 | 결정 |
|---|---|
| 현장 견적 DB 패널 | 접을 수 있게 남긴다 (왼쪽 DB 패널 / 가운데 표 / 오른쪽 내역서, 3단) |
| ① 위쪽 '항목 추가' 입력칸·[수정 불러오기] | 뺀다. 표에서 바로 입력한다. 그 칸의 'DB 저장'은 줄 메뉴로 옮긴다 |
| ② 공간별 보기 | 남긴다 (거르기만; 가나다순 정렬은 없어짐) |
| ③ 줄마다 마진 | 남긴다 (표 끝 '마진' 칸) |
| ④ 줄 선택 후 왼쪽 DB 패널에서 적용 | 남긴다 |
| 끌기 범위 | 줄은 같은 공사 안에서만. 다른 공사로는 줄 메뉴 '다른 공사로 옮기기' |
| 평형 조정 대상 | 면적 단위(m2·㎡·m²·평) 자동 체크 + 단위별로 켜고 끄기, 소수 첫째 자리 반올림 |
| 템플릿으로 저장 | 새 템플릿 또는 기존 템플릿 덮어쓰기(한 번 더 확인) |
| 공사별 색 | 화면에만. 인쇄·고객 서류는 지금처럼 회색 |

### 하지 않는 것

다른 공사로 끌어 놓기, 되돌리기(Ctrl+Z), 직원 앱(휴대폰) 견적 편집, 여러 줄 한꺼번에 선택해 옮기기, 서류 출력 화면의
배치 변경, 새 라이브러리 추가(끌기는 브라우저 기본 드래그로 만든다).

## 2. 공통 표 부품

### 2.1 나누기

- `app/lib/estimate-templates.ts`: 묶음 규칙을 둔다(순수 함수, 테스트가 직접 가져온다). 공사 이름은 PR #29와 같은 규칙
  `templateGroupLabel`(카테고리, 없으면 공정, 없으면 '기타 공사')로 정한다.
- `app/manager-weve-7519/estimate/grouped-lines-editor.tsx` (새): 공사별 표. 줄 배열을 받아 고친 줄 배열을 돌려준다(`onChange`).
  저장은 하지 않는다.
- `app/manager-weve-7519/estimate/template-document-preview.tsx`: 세부내역서 미리보기. 공사별 색과 크게 보기를 더한다.
- 화면마다 다른 칸은 표 부품의 선택 기능(props)으로 정한다.

| 기능 | 템플릿 작업 창 | 현장 견적 화면 |
|---|---|---|
| 분류·공종·품명 칸 | 직접 입력, [DB에서 다시 고르기] | 지금처럼 누르면 단계별 고르기 창 (`PickerCell`, `CommonNameCell`) |
| 마진 칸 | 없음 | 있음 (금액과 %) |
| 줄 선택(누르면 선택 표시) → DB 패널 적용 | 없음 | 있음 (`selectedLineId`) |
| 공간 보기 거르기 | 없음 | 있음 |
| '기본견적' 줄 맨 위 고정 | 없음 | 있음 (`isBaseEstimateLine`) |
| 'DB에서 못 찾음' 표시 | 있음 | 없음 |
| 줄 메뉴 'DB에 저장' | 없음 | 있음 |

### 2.2 공사 제목 줄

손잡이(⋮⋮) · 접기 · 색 점 · 공사 이름 · [이름 바꾸기] · 항목 수와 고객 소계 · [이 공사에 DB에서 추가] · [줄 추가] ·
[공사 복사] · [공사 삭제] · [공사 ↑] · [공사 ↓].

- **이름 바꾸기:** 새 이름(앞뒤 공백 제거, 빈 이름 불가)을 넣으면 그 공사 모든 줄의 `category`가 새 이름이 된다.
  - 다른 공사와 같은 이름이면 "OO와 합칠까요?"를 묻는다. 합치면 바꾼 공사의 줄이 그 공사의 줄 뒤에 붙는다.
  - 카테고리가 비어 공정이나 '기타 공사'로 묶인 공사도, 이름을 바꾸면 줄마다 `category`가 채워진다.
- **공사 복사:** 바로 아래에 `<이름> 복사`(겹치면 ` 복사 2`…) 공사를 만든다. 줄은 새 id를 받고 `category`가 새 이름이 된다.
  공정·품명·단가·DB 연결은 그대로다.
- **공사 삭제:** "OO N개 항목을 지울까요?"를 묻는다.
  - 현장 견적에서는 실행 내역과 연결된 줄 수도 알린다. 연결만 풀고(`unlinkWorkLinesFromLine`) 실행 내역은 지우지 않는다.
  - 모든 줄이 지워지면 현장 견적은 지금처럼 빈 줄 하나를 남긴다.

### 2.3 줄 메뉴 (⋯)

- **복제:** 바로 아래에 같은 줄을 새 id로 만든다.
- **다른 공사로 옮기기:** 지금 있는 공사 목록에서 고른다. 그 공사의 맨 아래로 간다(`setTemplateLineCategory`).
- **DB에 저장** (현장 견적에서만): 지금 '항목 추가' 칸의 'DB 저장' 창(견적 카테고리, 공통 항목 포함)을 그 줄 내용으로 연다.
  저장 동작은 지금 `saveLineDraftToDb`와 같다.
- **삭제:** 현장 견적에서는 지금 `deleteLine`처럼 실행 내역 연결을 알리고 연결을 푼다.

### 2.4 키보드

- **Tab / Shift+Tab:** 브라우저 기본대로 오른쪽 / 왼쪽 칸으로 간다.
- **Enter:** 같은 칸의 아래 줄로 간다. **Shift+Enter:** 위 줄로 간다. 다른 공사의 줄로도 이어서 간다(보이는 순서대로).
- **공사의 마지막 줄에서 Enter:** 그 공사에 빈 줄을 만들고 그 줄의 첫 입력 칸으로 간다.
- Enter로 칸을 옮기는 것은 입력칸·선택칸(`input`, `select`)에서만이다. 고르기 창을 여는 칸(분류·공종·품명 버튼)에서
  Enter를 누르면 버튼 기본 동작대로 창이 열린다.
- 한글 입력 중(조합 중, `isComposing`)에는 Enter를 칸 이동으로 쓰지 않는다. 이렇게 해야 마지막 글자가 사라지지 않는다.
- 칸 위치는 `data-row`(보이는 줄 순서)와 `data-col`(칸 이름) 속성으로 찾는다.

### 2.5 끌기

- 줄 손잡이를 끌면 **같은 공사 안에서만** 놓일 자리에 색 띠가 보이고, 거기에 놓인다. 다른 공사 위에서는 놓이지 않는다.
- 공사 제목 손잡이를 끌면 공사 전체 순서가 바뀐다.
- [공사 ↑↓]와 줄 ↑↓ 버튼은 그대로 둔다.
- 끌기와 순서 버튼은 아래 경우에 잠근다.
  - 공간 보기로 걸러 볼 때.
  - '기본견적' 줄과 그 공사(맨 위 고정).
- HTML 기본 드래그(`draggable`, `dragover`, `drop`)로 만든다. 새 라이브러리는 쓰지 않는다.

### 2.6 공사별 색

- 8가지 색을 공사 순서대로 돌려 쓴다(`groupColorIndex = 순서 % 8`). 이웃한 공사는 항상 색이 다르다.
- 표에서는 제목 줄 배경(옅은 색), 왼쪽 굵은 띠, 제목 글자, 색 점에 들어간다.
- 미리보기와 크게 보기에서는 공사 제목 줄에 같은 색이 들어간다.
- 인쇄(`@media print`)와 서류 출력 탭의 고객 서류에는 색을 넣지 않는다.
- 색 목록은 `app/lib/estimate-templates.ts`의 `GROUP_COLORS`(글자·띠 색과 배경색 짝)로 둔다. 글자 색은 흰 배경에서
  읽을 수 있는 진한 색으로 고른다.

### 2.7 세부내역서 미리보기·크게 보기

- 미리보기에 [크게 보기]를 둔다. 누르면 화면 전체 덮개 위에 가로 최대 1,120px, 큰 글씨로 같은 내역서를 보여 준다.
- [실행 금액 보기] 전환은 크게 보기에서도 된다. 닫기는 [닫기], Esc, 바깥 클릭이다.
- 현장 견적의 미리보기 제목 아래에는 `현장 이름 · 버전 이름 · 부가세 별도`를 보여 준다.

## 3. 현장 견적 화면

- **배치:** 왼쪽 DB 패널(지금 패널, [접기]로 44px 막대) / 가운데 공사별 표 / 오른쪽 미리보기([접기], [크게 보기]).
  화면 폭 1,280px 미만에서는 위아래로 쌓인다.
- **빠지는 것:** 위쪽 '항목 추가' 입력칸, [수정 불러오기], 줄 카드, '분류별/공간별 정렬' 칸(가나다순 정렬).
- **도구 줄:** [공사 추가] [DB에서 추가] [템플릿 불러오기] [템플릿 관리] [이 견적을 템플릿으로 저장] · 공간 보기(전체 / 공간들).
- **DB에서 추가:** 지금 고르기 창을 열고, 고른 항목을 그 DB 분류의 공사 맨 아래에 넣는다.
- **줄 선택 → DB 패널 적용:** 줄의 빈 곳이나 손잡이를 누르면 선택된다(테두리 표시). 왼쪽 패널의 [선택 행 적용]과
  [새 행 추가]는 지금처럼 동작한다.
- **마진 칸:** `수량 × (고객 단가 − 실행 단가)`와 %를 보여 준다.
- **'기본견적' 줄:** 그 줄의 공사를 항상 맨 위에 둔다(`pinBaseGroupFirst`). 끌기·순서·삭제 확인은 지금과 같다.
- **순서:** 견적을 열 때 `orderTemplateLinesByGroup` 후 '기본견적' 공사를 맨 위로 올린다. 이 순서가 저장된다.
  열기만 해서는 '저장 안 함' 상태가 되지 않게, 저장 상태 비교(`savedSnapshot`) 기준도 같은 순서로 맞춘다.
- **바뀌지 않는 것:** 저장 API와 형식, 실행 내역(`sourceLineId` 연결), 발주서, 서류 출력, 직원 앱.

## 4. 평형에 맞춰 수량 조정

- **템플릿 필드:** `baseArea`(기준 평형, 숫자, 1~500, 비워 둘 수 있음)를 더한다.
  - 템플릿 관리 창의 이름 옆에서 넣는다.
  - 목록 요약(`EstimateTemplateSummary.baseArea`)에도 보여 준다.
  - 서버는 숫자가 아니거나 범위 밖이면 400으로 막는다.
- **불러오기 창:** 공사 고르기 아래에 [평형에 맞춰 수량 조정] 체크를 둔다. 기본은 꺼져 있다. 켜면 아래가 나온다.
  - 기준 평형(템플릿 값으로 채움, 고칠 수 있음)과 이 현장 평형을 넣는다. 둘 다 0보다 커야 적용된다.
  - 비율을 보여 준다(예: `33 ÷ 30 = 1.1배`).
  - 단위 체크 목록: 고른 줄에 있는 단위들. `isAreaUnit`(공백 무시, 대소문자 무시: `m2`, `㎡`, `m²`, `평`)이 참인 단위는
    처음부터 체크돼 있다.
  - 체크된 단위의 줄만 `수량 × 비율`로 바꾸고 소수 첫째 자리에서 반올림한다(`scaleTemplateQuantities`).
  - 미리보기 합계와 결과 안내에 조정된 줄 수를 보여 준다.
- 조정은 최신 단가 반영(`refreshTemplateLines`)보다 먼저 한다. 수량만 바꾸고 단가 규칙은 그대로다.

## 5. 이 견적을 템플릿으로 저장

- 현장 견적 도구 줄의 버튼으로 창을 연다.
- **공사 고르기:** 불러오기 창과 같은 공사 체크 목록이다. '기본견적' 줄이 있는 공사는 처음부터 꺼져 있다.
  빈 줄(`isBlankEstimateLine`)은 빠진다.
- **새 템플릿:** 이름(템플릿 이름 규칙 그대로)과 기준 평형을 넣고 `saveTemplate`(id 없이)으로 저장한다.
- **기존 템플릿에 덮어쓰기:** 목록에서 고른다 → "OO 템플릿의 항목을 이 견적으로 바꿀까요?" 확인 → 그 템플릿을 읽어
  `updateTime`을 받고 같은 이름·기준 평형으로 줄만 바꿔 저장한다. 충돌(409)이면 다시 시도하라고 알린다.
- 줄은 새 id로 저장한다. 고객 단가·실행 단가·DB 연결은 그대로다.
- 현장 견적 자체는 바뀌지 않는다.

## 6. 순수 함수 (`app/lib/estimate-templates.ts`)

| 함수 | 하는 일 |
|---|---|
| `renameTemplateGroup(lines, from, to)` | 공사 이름 바꾸기. 같은 이름 공사가 있으면 그 뒤에 합친다 |
| `copyTemplateGroup(lines, label, newLabel, newId)` | 바로 아래에 새 id로 복사 |
| `removeTemplateGroup(lines, label)` | 공사 통째로 빼기 (지워진 줄 id 목록도 돌려줌) |
| `duplicateTemplateLine(lines, lineId, newId)` | 줄 복제 |
| `moveTemplateLineBefore(lines, lineId, beforeLineId \| null)` | 같은 공사 안에서 놓기. 다른 공사면 그대로 |
| `moveTemplateGroupBefore(lines, label, beforeLabel \| null)` | 공사 끌어 놓기 |
| `pinBaseGroupFirst(lines, isBase)` | '기본견적' 공사를 맨 위로 |
| `groupColorIndex(index)`, `GROUP_COLORS` | 공사 색 |
| `isAreaUnit(unit)`, `scaleTemplateQuantities(lines, ratio, units)` | 평형 조정 |
| `templateCopyGroupName(label, labels)` | `<이름> 복사`, ` 복사 2`… |

기존 `setTemplateLineCategory`, `insertIntoTemplateGroup`, `moveTemplateGroup`, `moveTemplateLineInGroup`,
